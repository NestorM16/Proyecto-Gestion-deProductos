# Sistema de Gestión de Productos (Estructuras de Datos)

Este proyecto implementa un sistema automatizado para la gestión, ordenamiento y búsqueda eficiente de un catálogo de productos simulado en una tienda en línea.

## 📁 Estructura del Proyecto

El sistema está dividido en cuatro módulos principales:
* **`gestion_productos.py`**: Contiene la definición de la clase `Producto` y la función para generar automáticamente el catálogo de prueba con 50 artículos aleatorios.
* **`ordenamiento.py`**: Implementación adaptada de los algoritmos de ordenamiento clásico (*Insertion Sort*, *Merge Sort* y *Quick Sort*) configurados por atributos específicos.
* **`busqueda.py`**: Módulo enfocado en localización de datos mediante *Búsqueda Binaria* (por ID) y *Búsqueda Lineal* (por coincidencia de nombre).
* **`main.py`**: Controlador principal encargado de coordinar la ejecución del flujo completo, ejecutar simulaciones y calcular las métricas de rendimiento en tiempo.

## 🚀 Cómo Ejecutar el Proyecto

Asegúrate de tener Python 3.11 instalado en tu sistema. Abre la terminal dentro del directorio del proyecto y ejecuta el archivo principal:

```bash
python main.py
```
